## Experience

**Research & Development Intern — Synopsys Inc.** *(Jan 2026 – Present)*

During my internship, I worked on AI-powered developer tooling and agentic systems for Ansys Mechanical scripting, focusing on making code-generation workflows more reliable, contextual, and efficient.

- Built a graph-based memory system for the Scripting Copilot that connects new queries with relevant historical queries and retrieves related code context for improved generation.
- Reduced memory pipeline latency by 67% (12s → 4s) by parallelizing three query-rephrasing pipelines with conditional result merging.
- Designed dependency-aware sequential execution for multi-step agent workflows, ensuring dependent code-generation and execution steps run only after their prerequisites are grounded.
- Built a corrective query mechanism that enables the agent to identify incorrect generated/executed steps, roll them back, and apply targeted fixes.
- Extended the Copilot's knowledge base with new Ansys Mechanical APIs and worked closely with development and testing teams to validate integrations across ~8,000 internal test cases.

This experience gave me hands-on exposure to LLM agents, RAG, graph-based memory, agent tool orchestration, code generation, and production-scale AI systems, while also strengthening my experience working across engineering and testing teams.
